01 / 题意与关键思路

为什么一个开关能把 24 V 变成 9.6 V？

输入电压固定，开关按频率 fs 周期性闭合。电感限制电流变化，电容承担电流差；输出不必在开关断开时立刻降为零。

关键是分别写出两种状态的电感电压和电容电流，再按持续时间加权。不要从 V = DVg 倒推电路。

vL = L · diL/dt　　iC = C · dv/dt

假设：器件理想，电阻负载，固定频率，忽略 ESR、导通压降、损耗与控制器。平均模型推导使用连续导通和小纹波近似。

02 / 完整推导

分别写出开关闭合和断开的方程

① 闭合，持续 dTs

输入通过开关连接电感。电感左端 Vg、右端 v，因此：

L · diL/dt = Vg − v
C · dv/dt = iL − v/R

② 断开且电感仍有电流，持续 (1−d)Ts

二极管提供续流路径，电感左端被理想二极管钳位在 0 V：

L · diL/dt = −v
C · dv/dt = iL − v/R

③ 电流已经降到零：DCM 多出来的状态

二极管关断，电感电流保持 0，电容独自给电阻供电：C · dv/dt = −v/R。此时不能继续用 −v/L 算出负电流，也不能沿用两状态 CCM 平均模型。

03 / 平均、直流与答案

对一个周期加权，先得到微分方程

L · dīL/dt = d(Vg−v̄) + (1−d)(−v̄) = dVg−v̄
C · dv̄/dt = īL−v̄/R

横线表示周期平均量，稳态取大写。令平均状态的导数为零：

0 = DVg−V　⇒　V = DVg
0 = IL−V/R　⇒　IL = V/R
默认参数的最终答案

V = 0.4 × 24 = 9.6 V
IL = 9.6 / 5 = 1.92 A
Ts = 1/20000 = 50 µs

平均输出稳定不代表瞬时输出完全不变。理想电容仍在充放电；默认开关模型的电压峰峰纹波约 17.4 mV，电流峰峰纹波约 1.31 A。

电压纹波很小，电流纹波可以相对明显。真实器件的 ESR 和损耗会改变这些数值。

04 / 小信号

为什么直流增益是 24，而不是 9.6？

分别叠加小扰动：d = D + d̂，v = V + v̂，iL = IL + î，vg = Vg + v̂g。代入平均方程、消去直流项，再舍去 d̂v̂g 这样的二阶小量：

L · dî/dt = Dv̂g + Vgd̂ − v̂
C · dv̂/dt = î − v̂/R

研究“占空比到输出”时令输入扰动 v̂g = 0。在零初始条件下做拉普拉斯变换：

Lsî = Vgd̂ − v̂　　î = (Cs + 1/R)v̂
(LCs² + Ls/R + 1)v̂ = Vgd̂
Gvd(s) = v̂/d̂ = Vg / (1 + sL/R + s²LC)

Gvd(0) = Vg = 24 V / 单位占空比
Δd = 0.01 时，ΔV ≈ 24 × 0.01 = 0.24 V
f₀ = 1/(2π√LC) ≈ 494.95 Hz
Q = R√(C/L) ≈ 7.31

9.6 V 是工作点，24 是工作点附近的斜率。Q 较大时，频响可能在 f₀ 附近出现峰值；高频渐近斜率约为 −40 dB/十倍频。

这不是闭环设计：此处没有补偿器、反馈环路或实际闭环带宽。DCM 下本节传递函数不适用。

05 / 错误与避免

最容易混淆的五件事

把占空比写成百分数直接代入
40% 应输入 0.4；增加 1 个百分点是 Δd = 0.01。
认为断开时电感电压是 0
续流时左端 0、右端 v，所以 vL = −v。
以为平均模型也应该有开关纹波
周期平均会滤去开关频率附近的变化。它预测平均量和慢动态。
用 CCM 公式解释轻载所有结果
先看 iL 是否触及零。出现零电流区间时，第三种状态必须参与计算。
把固有频率当作开关频率或闭环带宽
f₀ 由 L、C 决定；fs 是开关动作频率；闭环带宽还取决于控制器。
模型如何求解？

状态 x = [iL, v]ᵀ。每段使用同一个 A = [0, −1/L; 1/C, −1/(RC)]，导通段加入 b = [Vg/L, 0]ᵀ。利用矩阵指数精确推进，再求周期不动点。DCM 用零电流事件和电容放电方程拼接。波形均值用梯形积分；采样加密用来检查均值收敛。

频率响应来自 CCM 平均模型。阴影高频区及 DCM 的频响不能作为实际电路预测。软件教学结果不等于样机测试。
