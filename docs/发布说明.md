# 首次公开版本说明

准备日期：2026-10-25。版本：0.1.0。

## 公开范围

本版本将 Buck 与 Boost 交互学习实验台集中放在 `examples/buck-boost-lab/`，采用仓库根目录已有的 MIT 许可证。包含离线网页、MATLAB 脚本、参数、教学说明、数值测试、计算结果及历史验证截图。

不包含作者工作区的其他课题、私人学习计划、外部文献原文、Git 凭据或源项目的嵌套 `.git`。示例中的理论、参数和运行路径在仓库内自包含。原学习副本继续保留，公开仓库是单独维护的副本。

## 本次实际执行

在 Windows 上使用 Node.js 24.15.0，于公开副本运行：

- `npm test`：通过。Buck 的 9 组检查、Boost 的 11 组检查均通过；两种拓扑各包含 64 个参数边界组合。
- `npm run test:cross`：通过。Buck 对照 21 项指标、257 个波形采样点和 180 个频响点；Boost 对照 66 项数值指标，以及 257 个波形点、240 个频响点和 1890 个阶跃数据点。

上述跨端检查使用仓库已保存的 MATLAB 数据作为比较基线。本次未重新运行 MATLAB，也未重跑 Playwright 全套浏览器测试。历史浏览器截图已经查看，但它们不是本次重新生成的运行证据。

机器可读结果在 `examples/buck-boost-lab/validation/`：`javascript-results.json`、`boost-javascript-results.json`、`cross-results.json`、`boost-cross-results.json`。历史 MATLAB、浏览器记录和 `results/` 中数据继续保留。
