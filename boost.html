01 / 题意与关键思路

先存能量，再把电感电压与输入串联

Boost 与 Buck 的区别不只是公式的分母。导通时，电感接在输入与开关之间：电感储能，二极管反偏，电容独自给负载供电。关断后，电感为了保持电流，把开关节点电位抬高，输入与电感共同经二极管向输出供能。

在 CCM 中，输入电流就是连续的电感电流；二极管电流只在关断续流阶段出现。输出电阻电流由输出电压决定，不能把它与二极管脉冲电流混为一谈。

02 / 两个状态与第三种状态

沿电流路径分别列方程

导通，持续 dTs

L · diL/dt = Vg
C · dv/dt = −v/R

关断且二极管续流，持续 (1−d)Ts

L · diL/dt = Vg−v
C · dv/dt = iL−v/R

DCM：电流已经触零

iL = 0，二极管关断
C · dv/dt = −v/R

电感电流触零后禁止反向续流。此时电感两端电压为零，开关节点回到输入电位；输出电压仍由电容维持。若输出在空闲段降到输入电压以下，二极管会重新导通；本模块在这种超出支持工况的情形明确报错。

03 / 平均方程、直流解与答案

让正、负伏秒互相抵消

L · dīL/dt = dVg + (1−d)(Vg−v̄) = Vg−(1−d)v̄
C · dv̄/dt = (1−d)īL−v̄/R

稳态取大写并令平均导数为零：

V = Vg/(1−D)
IL = V/[R(1−D)] = Vg/[R(1−D)²]
默认：V ≈ 24/0.6 = 40 V；输出电流约 2 A；输入 / 电感平均电流约 3.333 A。

这个平均模型忽略了周期内纹波与开关状态之间的相关性。实际开关周期解与它有小偏差，网页会显示误差。轻载 DCM 时不能继续套用 Vg/(1−D)。

用小纹波近似估计边界：ΔiL ≈ VgD/(Lfs)，令 IL≈ΔiL/2，得到 Rcrit≈2Lfs/[D(1−D)²]。它是近似边界；页面模式判断来自电流是否真正触零。

04 / 为什么先降后升

电感电流来不及立即增加

占空比突然增大时，关断区间立即变短，电感向输出供电的时间减少；电感电流不能瞬间增大，短时间内电容向负载补足缺口，输出先下降。随后电感电流上升，输出最终升高。

C · dv̄/dt = (1−d)īL−v̄/R
阶跃刚发生时：Δ(dv̄/dt) = −IL · Δd / C < 0

这解释的是平均电压变化方向，不是电容电压跳变。开关实验以周期积分均值观察同一现象，原始瞬时电压还叠加了纹波。

从平均方程推到小信号模型

令 k=1−D。叠加小扰动，消去直流项并去掉两个小量的乘积；输入扰动取零：

L · dî/dt = −k v̂ + V d̂
C · dv̂/dt = k î − IL d̂ − v̂/R
(LCs² + Ls/R + k²)v̂ = (kV − LILs)d̂

用 kV=Vg、IL=Vg/(Rk²) 整理：

Gvd(s) = [Vg/k²] · [1−sL/(Rk²)] / [1+sL/(Rk²)+s²LC/k²]
f₀ = k/(2π√LC)
fRHP = Rk²/(2πL)

分子零点在正实轴，因此叫右半平面零点。它会增加相位滞后；控制带宽要留在其下方并结合相位裕度设计。本页没有 PI 或闭环控制器，也不会把 fRHP 当作可以直接使用的闭环带宽。

05 / 错误与避免

先区分三个“电流”和两种“变化”

导通时还以为输入直接给输出供能
先检查二极管偏置：导通时开关节点低于输出，二极管反偏，输出由电容供电。
把输入电流当成输出负载电流
输入电流等于电感电流；二极管电流是脉冲；输出负载电流约为 V/R。
认为占空比越大越好
固定输入和负载时，输出、电感平均电流及器件应力都会增加，理想模型不包含器件极限。
把轻载结果硬套 CCM 公式
先看电流是否触零，再选平均模型。
把调参后的两条稳态曲线当作瞬态
只有“运行阶跃”保留状态随时间的连续演变。上方稳态调参重新求周期解。
来源与数值实现

状态为 [iL,v]ᵀ。导通段用解析斜坡与电容指数放电，关断段用矩阵指数推进；电流触零事件由二分法定位。CCM 求线性周期映射不动点，DCM 求含触零事件的周期根。均值用状态积分恒等式计算；RMS 和峰值来自采样。阶跃保留原状态逐周期求解，再与 CCM 平均方程对照。
